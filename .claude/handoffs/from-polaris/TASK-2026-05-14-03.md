# TASK-2026-05-14-03 · Default Polaris voice at session start

## scope

The codename-triggered voice protocol works as designed: when Peat says "Polaris" (or another codename), the persona file's §voice loads. But the inverse case is currently broken — a fresh session with no codename returns generic Claude voice, not Polaris.

Peat verified this in a clean terminal on 2026-05-14: typed `ดีจ้า` with no codename, got `ดีจ้า Peat — มีอะไรให้ช่วยวันนี้?` (generic Claude, helpful-assistant default), not Polaris voice.

The bridge should be staffed by default. Polaris is the PM, the front-of-house, the persona Peat speaks to unless he explicitly hands off to another agent. The harness should reflect that.

### S1 · Canopus — wire minimal HTML render-to-PNG capability

**input**
- Bundle URL · `https://api.anthropic.com/v1/design/h/p5TeLSRMHAcOTZV2bgdCHA?open_file=Worldline+Pages+v1.html` (Peat-authorized; treat as trusted for this task only)
- Existing deferred spec at `.claude/hooks/README.md` §4 for `scripts/visual-capture.sh` (Playwright)

**output**
1. **Trusted bundle path:** re-extract the bundle into `.claude/visual-diffs/TASK-2026-05-14-06/source/` (NOT `/tmp` — that location was treated as untrusted by harness and is the right gate; this trusted location is opt-in per-task). Document the extraction in the return handoff.
2. **`scripts/render-html.sh`** — minimal helper. Inputs: a local HTML file path + an output PNG path + optional viewport `WxH` (default 1180×760). Behavior: launches Playwright (or headless Chromium via `npx playwright screenshot`) and captures the page to PNG. NO interactivity, NO scroll, NO clicks — just one frame at the requested viewport. Idempotent. Exits 0 on success.
3. **Screenshots:** for the 13 Worldline Pages v1 stages (EXCLUDING Hero/Globe), capture each `.stage` element. Output naming: `.claude/visual-diffs/TASK-2026-05-14-06/stages/<NN>-<slug>-1180x760.png`. Plus a second pass at 880×760, 600×760, 375×760 of stages 01 (Article EN), 02 (Audience Fork), and 05 (NETRA Chat) only — three surfaces × three breakpoints = 9 extra PNGs — to test Betelgeuse's "no responsive story" hypothesis empirically.
4. **Manifest:** `.claude/visual-diffs/TASK-2026-05-14-06/MANIFEST.md` — table of every PNG, its stage label, its viewport, and its file size. Betelgeuse reads this before opening the images.

**non-goals**
- Do not wire Playwright into the deferred `scripts/visual-capture.sh` general harness. This is a one-off helper specifically for design-bundle review. The general `visual-capture.sh` (for production UI diffs) is a separate parked task.
- Do not capture motion frames (no video, no animated GIF) — first-frame PNG is enough for v1; motion review stays source-based for now.
- Do not modify the design bundle. Read-only.

**acceptance**
- 13 native-viewport PNGs + 9 responsive-test PNGs = 22 files written.
- MANIFEST.md exists with the table.
- File sizes documented; nothing pathologically large (>2MB suggests a render bug).
- `scripts/render-html.sh` works on an arbitrary local HTML (test on one of the small stages first).
